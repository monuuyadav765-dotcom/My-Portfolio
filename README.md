# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, education, projects, and journey as a B.Tech Computer Science (Data Science) student.

## 🚀 About the Project

This is a responsive personal portfolio website designed to introduce myself and highlight my technical skills, academic background, and development projects. It provides visitors with an overview of my work and a way to connect with me.

## 🛠️ Technologies Used

- **HTML5** – For structuring the website.
- **CSS3** – For styling, layouts, animations, and responsive design.

## ✨ Features

- Personal introduction and profile section.
- About Me section.
- Technical skills showcase.
- Educational background.
- Projects portfolio.
- Social media links.
- Contact information.
- Responsive layout for different screen sizes.

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/personal-portfolio.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! The portfolio website will be displayed.
